# Local Setup — spark-lakehouse-statcan

> Everything you need to run the full pipeline on your local machine. No cloud account required.

---

## Prerequisites

- Python 3.8+
- Java 8 or Java 11 (required by Apache Spark — `java -version` to check)
- Git

---

## 1. Clone the Repository

```bash
git clone git@github.com:sandeepfreax/data-engineering-blogs.git
cd data-engineering-blogs/spark-lakehouse-statcan/local-setup
```

---

## 2. Create a Virtual Environment

```bash
python -m venv .venv
source .venv/bin/activate       # macOS/Linux
```

---

## 3. Install Dependencies

All dependencies — PySpark, Delta Lake, dbt, Pandas, and supporting libraries — are pinned in `requirements.txt`.

```bash
pip install -r requirements.txt
```

---

## 4. Configure Environment Variables

Copy the example env file and fill in your local paths:

```bash
cp .env.example .env
```

Open `.env` and set the paths to your downloaded StatCan CSV files:

```dotenv
# Paths to raw StatCan CSV files
BRONZE_PROVINCE_PATH=/absolute/path/to/14-10-0287-03.csv
BRONZE_INDUSTRY_PATH=/absolute/path/to/14-10-0355-02.csv

# Silver Delta table output paths
SILVER_PROVINCE_PATH=/absolute/path/to/local-setup/delta_tables/silver/province
SILVER_INDUSTRY_PATH=/absolute/path/to/local-setup/delta_tables/silver/industry

# Add any other paths used by your pipeline stages
```

> The pipeline runner automatically loads `.env` at startup — no need to `source` it manually.

---

## 5. Download the StatCan Data

Download the two CSV tables from Statistics Canada:

| Table | ID | Direct Link |
|-------|----|-------------|
| Labour Force Survey — Province | `14-10-0287-03` | [statcan.gc.ca](https://www150.statcan.gc.ca/t1/tbl1/en/dtbl!downloadTbl/csvDownload/14-10-0287-03.zip) |
| Labour Force Survey — Industry | `14-10-0355-02` | [statcan.gc.ca](https://www150.statcan.gc.ca/t1/tbl1/en/dtbl!downloadTbl/csvDownload/14-10-0355-02.zip) |

Unzip and update the paths in `.env` accordingly.

---

## 6. Install dbt Packages

```bash
cd dbt/
dbt deps
cd ..
```

> This step is also automated as the first dbt stage in the pipeline runner, but running it once manually ensures your setup is correct before the full pipeline run.

---

## 7. Run the Pipeline

From the `local-setup/` directory:

```bash
# Full pipeline (Bronze through dbt)
python spark/06_pipeline_runner.py

# Skip Bronze ingestion if already loaded
python spark/06_pipeline_runner.py --skip-bronze

# Run a single stage for debugging
python spark/06_pipeline_runner.py --stage silver
python spark/06_pipeline_runner.py --stage dq
python spark/06_pipeline_runner.py --stage scd2
python spark/06_pipeline_runner.py --stage mart
python spark/06_pipeline_runner.py --stage dbt
```

## Cleaning Up for a Fresh Run

To reset all generated tables and run from scratch:

```bash
rm -rf delta_tables/silver delta_tables/gold
rm -rf spark-warehouse/dim_geo spark-warehouse/fct_employment_monthly
cd dbt && dbt clean && cd ..
```

Then re-run with `--skip-bronze` if Bronze is still intact, or the full pipeline to start completely fresh.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `SILVER_PROVINCE_PATH not provided` | Check `.env` exists in `local-setup/` and paths are absolute |
| `dbt found packages but 0 installed` | Run `cd dbt && dbt deps` |
| `No such file or directory: .../local-setup/local-setup` | Upgrade to the fixed `05_pipeline_runner.py` (PROJECT_ROOT fix) |
| Pipeline fails at a specific stage | Run `python spark/05_pipeline_runner.py --stage <name>` to isolate and debug |
